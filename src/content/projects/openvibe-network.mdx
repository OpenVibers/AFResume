One account for every OpenVibe site. The Network issues RS256 access tokens and rotating refresh tokens, publishes discovery and JWKS, and every other service verifies offline against the cached key set, so a Network outage never blocks a logged-in viewer.

**Sign-in that gets out of the way.** Silent cross-site hand-off, a read-only SSO probe, and FedCM (the Network is an identity provider), so clicking from Live to Tools never shows a login screen twice. Multi-account switching and anonymous identities that can link later.

**Wallet and notifications.** Atomic credit, debit and transfer endpoints with idempotency keys for OpenCoins; a unified inbox with web push, email and Discord delivery and rate governance (go-live cooldowns, per-streamer and per-user daily caps).

**Shared chrome.** One package serves the navbar, footer, theme loader, notification UI, account switcher and the animated OV brand mark to every site. Navigation is ranked by an anonymous per-host page-view beacon that honours Global Privacy Control, and the footer copy is regenerated daily by an AI job behind a budget.

**Themes.** About 30 built-in themes synced network-wide, with derived tokens, theme-following favicons and per-user display preferences for motion and text size.
