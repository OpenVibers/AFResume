Share code, logs or a screenshot and get a short link that works anywhere. Every page is rendered on the server with progressive JavaScript on top, so pastes read fine with scripts off and index cleanly with canonical, Open Graph and Article structured data.

The service owns no data: paste requests stream through to Live, the only service that can resolve the visitor's identity, and sign-in uses a silent `prompt=none` flow so a Live session simply appears here.
