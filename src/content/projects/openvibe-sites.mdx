openvibe.chat, .codes, .blog, .wiki, .news, .reviews, .tips, .vip, .trade, .host, .deals, .coupons and openre.stream all needed a real front door before they became apps. `sites.json` plus `build.js` emit a directory per domain and a matching nginx vhost; each page carries the shared navbar, footer and theme loader, so the whole network reads as one brand with many rooms.
